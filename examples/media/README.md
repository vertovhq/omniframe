# Sample media

Files for the judge quickstart in the main [README](../../README.md).

- `sample-voiceover.txt`: the text of the sample voiceover. OmniFrame voices it when you run the example
  (`synthesize_voiceover`). No audio file is stored in the repository.

For production-quality voice, add your ElevenLabs API key to .env (ELEVENLABS_API_KEY). Without a key OmniFrame falls back to a free voice so the example still runs.
