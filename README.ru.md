# ARGUS

MCP-студия вертикального видео (TikTok, YouTube Shorts, YouTube). ИИ-модель в твоём клиенте
режиссирует монтаж. ARGUS даёт ей глаза, уши и руки: смотрит и слушает футаж, делает озвучку,
рендерит, проверяет техническое качество и упаковывает выгрузку.

Автор: VertovHQ. Сделано в Kiro для Kiroween 2026. Репозиторий: https://github.com/vertovhq/argus

English version: [README.md](README.md).

## Что делает ARGUS

Все творческие решения принимает модель. ARGUS не оценивает и не ранжирует историю, стиль или
оригинальность. Он возвращает материал, который модель может воспринять (картинки, таймкоды,
транскрипт, звуковые события), и запускает детерминированные проверки только технических дефектов:
размер, частоту кадров, громкость, пики, чёрные провалы и длину аудио.

ARGUS покрывает три сценария:

1. **Референс → новое видео.** Даёшь референсный клип. Модель его смотрит и делает продолжение,
   аналог или твою идею в той же манере.
2. **Твой футаж → смонтированное видео.** Режешь запинки, повторы и долгие паузы из своей съёмки.
   Добавляешь субтитры, зумы, графику, звуковые эффекты и музыку.
3. **Идея → видео с нуля.** Кинетическая графика из JSON-плана, AI-клипы Veo или оба варианта.

Каждый сценарий заканчивается одним и тем же: файл 9:16 и/или 16:9, готовый к загрузке, обложка и
`post.md` с заголовком, описанием и хэштегами. Публикация остаётся ручной: ARGUS не вызывает API
платформ.

## Чем ARGUS отличается от video-shotcraft и OpenFilm

[video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) (Apache 2.0) — скилл для
Claude Code и Codex. Он делает промо продукта из скриншотов и текста, рисует через Remotion.
[OpenFilm](https://github.com/openfilm/openfilm) превращает кодинг-агента в режиссёра фильма: фильм —
папка HTML-страниц, есть свой редактор на десктопе. ARGUS — MCP-сервер, поэтому любой MCP-клиент
может им управлять, в том числе Kiro. Он стартует с референсного видео и делает его продолжение.
Он монтирует твою собственную съёмку, затем проверяет результат (размер кадра, громкость, true peak,
чёрные провалы, длину аудио) и экспортирует пакет для загрузки. Звуковые эффекты синтезируются в коде
(whoosh, pop, hit) и могут смешиваться со звуками CC0 с Freesound. Одно готовое видео 9:16 стоит
N credits и занимает M min. Цифры появятся после демо.

## Быстрый старт без ключей

Без ключей API работают кинетическая графика, бесплатные голоса edge-tts, просмотр и кадрирование
видео, QA и экспорт. Клипам Veo нужен вход в Flow или ключ API (см. [Честные примечания](#честные-примечания)).

1. Установи (см. [Установка](#установка)).
2. Запусти `argus-doctor`. Он выводит таблицу: ✓ готово, ✗ не хватает (с командой установки),
   ⚠ необязательно.
3. Подключи MCP-клиент (см. [Подключение клиента](#подключение-клиента)) и перезагрузи MCP-серверы.
4. Напиши в чат, по порядку (файлы лежат в [`examples/media/`](examples/media/README.md)):
   - `Вызови studio_guide и следуй рабочему порядку из него.`
   - `Посмотри examples/media/moving-shapes-8s.mp4 через watch_video, потом get_frames на 2 и 6 секундах. Опиши, что видишь.`
   - `Прочитай examples/media/sample-voiceover.txt и озвучь его через synthesize_voiceover, проект demo.`
   - `Отрендери stills из examples/plans/graphics_9x16.json в проекте demo на 1, 4 и 8 секундах. Покажи кадры.`

   Потом попроси preview, final, `qa_verify_video` и `export_package`. План читает
   `audio/voice.words.json` из папки проекта, поэтому озвучка и рендер должны идти в один проект.

   For production-quality voice, add your ElevenLabs API key to .env (ELEVENLABS_API_KEY). Without a key ARGUS falls back to a free voice so the example still runs.

## Установка

Требования: Python 3.11+, ffmpeg в PATH, Node.js 18+ (для движка Remotion). Windows, macOS и Linux.

```bash
git clone https://github.com/vertovhq/argus.git
cd argus
python -m venv .venv
# Windows (PowerShell): .venv\Scripts\Activate.ps1      macOS/Linux: source .venv/bin/activate
bash install.sh     # Windows: powershell -ExecutionPolicy Bypass -File install.ps1
```

Скрипт установки ставит Python-пакет, голос edge-tts, Node-пакеты движка и создаёт `.env` из
`.env.example`. Он также пробует поставить Chromium для необязательного пути Flow. Запускай его в
активированном venv. Пошагово: [INSTALL.md](INSTALL.md).

### Без клонирования: uvx или Kiro Power

С установленным [uv](https://docs.astral.sh/uv/) сервер запускается прямо с GitHub. Эта команда
подходит как MCP-команда:

```bash
uvx --from git+https://github.com/vertovhq/argus argus-studio
```

При первом запуске сервер ставит движок графики в `~/.argus/engine` в фоне. Нужны Node.js 18 или новее
и ffmpeg в PATH. Ход установки видно в инструменте `doctor` или в
`uvx --from git+https://github.com/vertovhq/argus argus-doctor`. Ключи лежат в `~/.argus/.env`.

Папка [`kiro-power/`](kiro-power/README.md) — power для Kiro. Она ставит тот же сервер и рабочий гид
одним действием.

## Подключение клиента

Kiro читает `.kiro/settings/mcp.json` в рабочей папке или `~/.kiro/settings/mcp.json` для всех папок:

```json
{
  "mcpServers": {
    "argus": {
      "command": ".venv/Scripts/python.exe",
      "args": ["-m", "argus"],
      "env": { "OMNIFRAME_OUTPUT_DIR": "./output" }
    }
  }
}
```

На macOS и Linux используй `.venv/bin/python`. В пользовательском файле укажи абсолютный путь к
Python из venv. Ключи держи в `.env`, а не в этом файле. Другие варианты:
[`examples/mcp-config.example.json`](examples/mcp-config.example.json).

Любой другой MCP-клиент подключается так же: запускай `python -m argus` из venv или команду
`argus-studio` после установки.

## Инструменты

| Инструмент | Что делает | Ключи |
|---|---|---|
| `studio_guide` | Рабочий порядок, доступные инструменты и провайдеры, сохранённые предпочтения пользователя. Вызывается первым в каждой сессии | не нужны |
| `watch_video` | Смены кадра, контактные листы, слова транскрипта (faster-whisper, необязательно) и звуковые события видео: картинками и таймкодами | не нужны |
| `get_frames` | Точные кадры видео картинками, можно с кадрированием | не нужны |
| `voice_options` | Голоса, модели и провайдеры, доступные сейчас | необязательно |
| `synthesize_voiceover` | Аудио озвучки и тайминги слов (`{w, s, e}`), мастеринг до -14 LUFS. Провайдеры: edge (бесплатно), ElevenLabs, Gemini | не нужны (edge); ключи улучшают качество |
| `generate_veo_clip` | Клип Veo 3.1 через твою сессию Flow (`provider="flow"`). API-путь отклоняется (см. Честные примечания) | вход в Flow |
| `flow_login` | Разовый вход в Flow: открывает окно браузера, ты входишь, профиль сохраняется | аккаунт Google |
| `render_video` | План → stills, preview или final в 9:16 или 16:9: графика, клипы футажа, субтитры, музыка, звуковые эффекты | не нужны |
| `job_status` | Состояние и результат долгой задачи, которая вернула `job_id` | не нужны |
| `qa_verify_video` | Технические проверки (размер, fps, громкость, true peak, чёрные провалы, длина аудио) и кадры для просмотра | не нужны |
| `export_package` | Финальная папка с видео, обложками и `post.md`. Отказывает, если QA нашёл жёсткий дефект | не нужны |
| `calculate_beat_grid` | Темп и сетка битов музыкального трека | не нужны |
| `search_sfx`, `download_sfx` | Звуки Freesound (по умолчанию CC0). Читают публичные страницы Freesound | не нужны |
| `run_script` | Запуск твоих Python-скриптов из папки скриптов | не нужны |
| `learn_and_record_memory` | Сохраняет постоянное предпочтение пользователя; `studio_guide` отдаёт его в следующих сессиях | не нужны |
| `doctor` | Проверка окружения: Python, ffmpeg, Node, движок, numpy, Pillow, дополнительные пакеты, ключи, папка вывода | не нужны |

## Пример плана

План — JSON-описание сцен. Этот пример проверен моделью плана из `src/argus/plan.py`:

```json
{
  "version": 2,
  "format": "9:16",
  "style": "dark",
  "hud": {
    "at": 0.5, "until": 5.5,
    "rows": [
      {"label": "ДО СРОКА", "value": "365 ДНЕЙ"},
      {"label": "РАБОЧИЕ", "value": "0/100"}
    ],
    "pos": "top",
    "accent_changes": [{"at": 3.0, "row": 1, "value": "20/100"}]
  },
  "scenes": [
    {"at": 0.0, "kind": "words", "text": "стоп скроллить это сейчас"},
    {"at": 2.5, "kind": "title", "kicker": "глава 1", "text": "что тут происходит"},
    {"at": 5.0, "kind": "counter", "value": 87, "suffix": "%", "sub": "не доходят до конца"},
    {"at": 6.5, "kind": "cta", "text": "забирай бесплатно", "handle": "@you"}
  ],
  "audio": {"voice": {"src": "audio/voice.mp3"}}
}
```

`hud` — оверлей уровня плана, а не сцена: тёмная плашка с моноширинными значениями, которая
держится поверх всех сцен в своём интервале. `accent_changes` меняет значение строки и подсвечивает
его. Больше планов — в [`examples/plans/`](examples/plans).

Порядок работы одинаковый для любого плана: `synthesize_voiceover`, если в видео есть озвучка, затем
`render_video` в режиме `stills` (модель смотрит каждый кадр), потом `preview`, `final`,
`qa_verify_video` и `export_package`.

## Честные примечания

- **Veo API закрыт.** Google закрыла Veo 3.1 Preview в Gemini API 2026-10-22
  (https://aistudio.google.com/docs/video). `generate_veo_clip` с `provider="api"` возвращает это
  сообщение и не делает запроса.
- **Flow включается вручную и хрупок.** `provider="flow"` управляет твоей сессией flow.google через
  Playwright. Нужен один `flow_login`, один аккаунт на человека, а работа зависит от интерфейса Google.
  Селекторы лежат в `src/argus/tools/flow_browser.py`.
- **Субтитры берутся из плана.** Движок рисует их из блока `captions` плана. Файлов `.ass` ARGUS не пишет.
- **Промпты уходят в Veo как написаны.** ARGUS их не переписывает, чтобы обойти правила контента.
- **Бесплатный тариф ElevenLabs** может не давать библиотечные голоса через API. `voice_options`
  сообщает об этом.

## Как модель работает с ARGUS

- Модель первым делом вызывает `studio_guide`. Он возвращает рабочий порядок, доступные инструменты
  и провайдеры и сохранённые предпочтения пользователя.
- Долгая работа (рендеры, Veo, QA длинных файлов) возвращает `job_id`. Модель опрашивает `job_status`.
- В сборке использовались Claude Opus 5.5 для планирования и аудита, Claude Sonnet 5.5 для основных
  задач и Claude Haiku 5.5 для мелких задач, всё внутри Kiro. Монтаж настолько хорош, насколько хорошо
  модель направляет ARGUS, поэтому каждый шаг заканчивается кадрами, которые пользователь может
  проверить.

## Как проект сделан с Kiro

- **Спецификация.** `.kiro/specs/argus-v2/`: требования, дизайн и список задач. В каждой задаче
  указаны разделы дизайна для чтения, файлы и шаги проверки.
- **Steering.** `.kiro/steering/product.md`, `tech.md` и `engine.md` задают правила продукта (без
  творческих затворов), соглашения кода (инструменты возвращают картинки через `tool_result`, долгая
  работа идёт задачами) и правила движка.
- **Хуки.** `.kiro/hooks/`: проверка типов движка при каждом сохранении файла исходников движка и
  запуск тестов, когда задача спецификации отмечена выполненной.
- **MCP.** `.kiro/settings/mcp.json` подключает ARGUS к Kiro. После перезагрузки чат вызывает его
  инструменты.
- **Журнал сборки.** [`docs/BUILD_LOG.md`](docs/BUILD_LOG.md): запись на каждую задачу — модель,
  что сделано, ошибки и их исправления, что проверено.

## Раскрытие

ARGUS вырос из ATLAS, личного скрипта автора, написанного до хакатона. Первый MCP-прототип (v1) собран
в ZCode в период подачи (первый коммит 2026-11-04). v2 переписан по спецификации в Kiro; спецификация,
steering, хуки и журнал сборки лежат в `.kiro/` и `docs/BUILD_LOG.md`.

## Категория: Frankenstein

Правила Kiroween просят проект, который «stitch together a chimera of technologies into one app»
(https://kiroween.devpost.com/rules). ARGUS это делает. Чат-модель управляет покадровым React-рендером
(Remotion), обработкой аудио и видео в ffmpeg, распознаванием речи (faster-whisper), голосами
(edge-tts, ElevenLabs, Gemini), генерацией видео (Veo через Flow) и звуками Freesound. Модель видит
видео через контактные листы и стоп-кадры.
