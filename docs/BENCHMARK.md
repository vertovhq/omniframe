## Что такое ECC

Agent-harness для кодинг-агентов: 71 агент, 314 скиллов, 98 команд, memory vault,
AgentShield. Один мейнтейнер. Монетизация: **ECC Pro — GitHub App, ~$19/сид/мес
за приватные репо** + спонсоры. Призов хакатонов в репо не заявлено — это чистый
органик-гринд: install-discipline, кросс-харнесс адаптеры, безопасность.
